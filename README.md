# The Vantage Club

Official website for **The Vantage Club**.

## Structure

- `index.html` — website
- `style.css` — visual system and responsive layout
- `script.js` — navigation, motion, and scroll interactions
- `assets/logo.png` — supplied club logo

## Deploy with Render

This is a static site and requires no build step.

1. Create a new GitHub repository.
2. Upload the contents of this folder to the repository.
3. In Render, create a **Static Site** and connect the GitHub repository.
4. Use:
   - **Build Command:** leave empty
   - **Publish Directory:** `.`
5. Deploy.

Render can then automatically redeploy the site whenever changes are pushed to GitHub.

## Editing

The website intentionally uses plain HTML, CSS, and JavaScript so the club can maintain it without a framework.
